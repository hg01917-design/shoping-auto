# 벤더 상품 등록 스크립트 (유유팩토리 등)

zip으로 받은 벤더 상세·대표 이미지를 잘라 네이버 커머스API로 등록한 스크립트 모음.
원래 `신규벤더상품/_work/`, `헬스펫_블로그형_상세페이지/`에서 실행했고, 경로는 그 폴더 기준(`ROOT = 스크립트 폴더의 상위`)이라 복사본을 그대로 돌리려면 경로 조정이 필요하다.

- `slicer.py` 상세 이미지를 여백 기준으로 자름 / `cands.py`, `extend_images.py` 대표 이미지 후보 추출·추가
- `register_*.py` 상품군별 등록 (헬스펫, 폭싹·세안타올, 누룽지·미숫가루, 흑마늘, 텀블러, 호호바, 젤리, 순유 화장품)
- 인증은 `scripts/naver_auth.py`를 사용하며 키는 저장소에 없다.
