# Post Registration Optimization Rules

등록일이 오래된 상품부터 하루 10개를 점검한다. 상품번호, 상품명, 주요 키워드, 현재·이전 노출 순위, 클릭수, 찜 수, 리뷰 수, 마지막 수정일, 점검 시각을 확인한다.

노출 순위가 낮거나 클릭률이 낮거나 오래 등록됐지만 유입이 적은 상품을 우선 개선한다. 핵심 키워드 순서 변경, 대표 키워드 교체, 보조 키워드 추가, 속성·태그 보완, 대표이미지 교체, Listing별 키워드 재배치를 사용할 수 있다. 근거가 없는 매일 상품명 변경은 하지 않는다.

`output/rank-optimization.json`에는 상품번호, 수정 전후 상품명·키워드·순위, 수정 사유, 작업 시각을 남긴다.

찜 할인 100원, 알림받기 혜택 100원, 리뷰 적립 100원과 필요 시 추가 쿠폰을 활용할 수 있으나 가격 계산은 [pricing.md](pricing.md)의 기준을 다시 적용한다.
