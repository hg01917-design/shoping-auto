# Product Identification Rules

## 상품 등록 경로

상품 등록은 사용자 제공 이미지 또는 코스트코 공식몰 기준 경로를 지원한다. 사용자가 직접 업로드하거나 지정한 상품 폴더의 이미지는 1차 근거다. 코스트코 공식몰 기준으로 요청한 경우에는 공식몰 정보를 기준으로 등록자료를 수집한다.

## 사용자 이미지 분석

사용자 이미지에서 브랜드, 상품명, 용량, 수량, 맛·종류, 구성, 원산지, 제조사, 라벨 문구, 가격표의 최종 표시가를 최대한 추출한다. 사용자 이미지는 최신 실물 근거로 보며 파일명, 촬영일, 매장 가격표 연도만으로 구형 상품이라고 판단하지 않는다.

## 동일상품 검색

이미지 분석 후 네이버 스마트스토어, 코스트코 코리아 공식몰 순으로 동일상품을 확인한다. 브랜드만 같다는 이유로 판단하지 않는다. 브랜드, 제품명, 용량, 수량, 맛, 포장 단위, 구성을 대조해 실질적으로 같을 때만 동일상품으로 인정한다.

## 정보 충돌

제품 외형·구성·라벨은 사용자 이미지를 우선한다. 가격도 사용자 이미지의 가격표를 우선한다. 코스트코 공식몰 또는 네이버 스마트스토어는 보완 정보로만 쓴다.

## 코스트코 공식몰 기반 등록

공식몰에서 직접 상품을 가져올 때 공식 상품명, 브랜드, 용량, 구성, 상품 정보, 대표·상세 이미지, 상세 설명을 사용할 수 있다. 이 경우에도 용량, 구성, 맛, 수량을 확인한다.
