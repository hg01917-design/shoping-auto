# 상세페이지 디자인·정렬 규칙

## 핵심 디자인 원칙

상세페이지는 **크고, 가운데 정렬하고, 여백을 넉넉하게 두고, 문장은 짧게 쓴다.**

깔끔함, 큰 글씨, 넓은 여백, 가운데 정렬, 짧고 읽기 쉬운 문장, 제품 중심 구성, 손으로 적은 메모나 편지 같은 자연스러운 포인트, 과도한 배너나 장식이 없는 미니멀 디자인을 기본으로 한다. 보고서나 정보표처럼 보이게 하지 않으며, 첫 화면에서 소비자가 상품의 핵심을 바로 이해하게 한다.

실제 상품 정보의 근거는 사용자 이미지, 제품 라벨, 코스트코 공식몰, 확인된 공식 상품정보다. 과장 표현과 확인되지 않은 효능·성능·기능은 쓰지 않는다.

## 1. 기본 정렬과 컨테이너

메인 상품명, 용량·수량·구성, 핵심 강조문, 손편지 느낌 문구, 소제목, 본문, 상품 이미지, 특징, 구성 설명, 구매 안내를 기본적으로 모두 가운데 정렬한다.

```html
text-align:center;
```

좌측 정렬은 특별한 이유가 있을 때만 쓴다. 텍스트와 이미지를 좌우로 나누는 2단 레이아웃은 쓰지 않는다. 모바일에서 위에서 아래로 자연스럽게 읽는 세로형 중앙 레이아웃을 쓴다.

전체 콘텐츠는 중앙에 배치하며 최대 폭은 800~900px, 기본값은 860px이다.

```html
<div style="
max-width:860px;
margin:0 auto;
background:#fff;
font-family:Arial,'Noto Sans KR',sans-serif;
color:#111;
line-height:1.8;
text-align:center;
word-break:keep-all;
">
```

## 2. 글자 크기

기존 쇼핑몰처럼 작은 글씨를 사용하지 않는다. 모바일에서도 한눈에 읽히도록 크게 쓴다.

### 메인 타이틀

- 권장: 36~46px, 기본 42px
- 굵기: 700~800
- 줄간격: 1.35~1.5
- 여백: `margin:90px 20px 25px`

상품명이 길면 한 줄에 억지로 넣지 않고 2~3줄로 자연스럽게 줄바꿈한다.

```html
<div style="font-size:42px;font-weight:800;line-height:1.4;text-align:center;margin:90px 20px 25px;word-break:keep-all;">
커클랜드 그릭요거트<br>907g × 2개
</div>
```

### 핵심 강조문

- 권장: 28~36px, 기본 30~32px
- 줄간격: 1.65
- 여백: `margin:25px 30px 60px`

```html
<div style="font-size:31px;font-weight:500;line-height:1.65;text-align:center;margin:25px 30px 60px;word-break:keep-all;">
꾸덕하고 담백하게,<br>매일 즐기는 플레인 요거트
</div>
```

### 소제목과 본문

- 소제목: 28~34px, 굵기 700, 기본 여백 `margin:90px 20px 35px`
- 본문: 20~24px, 기본 22px, 20px보다 작게 쓰지 않음
- 본문 줄간격: 1.7~1.9

본문은 한 문단에 1~3문장으로 짧게 쓴다.

```html
<div style="font-size:22px;font-weight:400;line-height:1.85;text-align:center;margin:30px 35px 70px;word-break:keep-all;">
과일이나 그래놀라와 곁들이면<br>간단하게 즐기기 좋은 플레인 타입입니다.
</div>
```

### 상품 정보표

정보표는 18~20px으로 만들고 셀 내부 여백을 충분히 둔다. 정보표는 상세페이지 후반부에 배치하며 첫 화면이나 상품 소개 중간에는 넣지 않는다.

확인 가능한 상품명, 브랜드, 용량, 수량, 구성, 식품유형, 원산지, 제조사, 보관방법, 원재료, 기타 정보를 넣을 수 있다. 확인할 수 없는 정보는 추측하지 않는다.

## 3. 손편지 느낌 포인트

전체를 손글씨체로 만들지 않는다. 약 80%는 깔끔한 고딕계열, 약 20%만 손편지 느낌 포인트로 쓴다. 상품 첫 소개, 이미지 사이, 특징 소개 전후, 마지막, 짧은 한 줄 강조에서 선택적으로 쓴다.

예: `담백하게, 오늘도 한 스푼 :)`, `이런 요거트 찾으셨다면`, `냉장고에 하나쯤 있으면 든든해요`, `오늘은 조금 가볍게`

손편지 문구도 가운데 정렬한다. 손글씨 폰트가 안정적으로 표시되지 않아도 디자인이 무너지지 않게 하며, 상품명·용량·구성 같은 구매 정보는 항상 HTML 텍스트로 표시한다.

## 4. 첫 화면

첫 화면은 다음 순서로 단순하게 구성한다.

```text
메인 상품명
↓
용량 / 수량 / 구성
↓
짧은 손편지 느낌 강조문
↓
넓은 여백
↓
큰 상품 이미지
```

첫 화면에는 작은 정보표, 긴 설명문, 지나치게 많은 특징, 복잡한 아이콘, 과도한 배너, `PRODUCT STORY` 같은 작은 영문 제목을 넣지 않는다.

## 5. 이미지 배치과 상세 흐름

모든 상품 이미지는 가운데 정렬한다. 이미지 폭은 가능한 페이지 폭의 80~100%를 쓰며, 작은 이미지를 여러 장 빽빽하게 배열하거나 대표이미지를 의미 없이 반복하지 않는다.

```html
<div style="text-align:center;margin:50px 0 90px;">
  <img src="IMAGE_URL" style="max-width:100%;height:auto;display:block;margin:0 auto;">
</div>
```

기본 흐름은 큰 상품명 → 구성·용량 → 짧은 감성 문구 → 첫 번째 큰 상품 이미지 → 핵심 특징 2~4개와 짧은 설명 → 나머지 상품·라벨 이미지 → 후반 상품 정보다. 텍스트와 이미지 사이에는 충분한 여백을 둔다. 핵심 설명마다 이미지를 억지로 끼우지 않으며, 첫 이미지 아래에 설명을 자연스럽게 모은 뒤 나머지 이미지를 배치할 수 있다.

긴 원본 상세 이미지는 일정 높이로 자동 절단하지 않는다. 제목, 표, 설명, 콘텐츠 블록이 끝나는 여백 지점에서만 분할한다. 이미지 사이 설명은 실제 상품 특징을 바탕으로 쓰고, 동일 문장을 여러 상품에 반복하지 않는다.

## 6. 상품 특징과 여백

특징은 긴 설명 대신 짧고 강하게 보여 준다. 숫자, 제목, 설명을 모두 가운데 정렬한다.

```text
01

담백한 플레인 타입

과일이나 그래놀라와 함께
취향에 맞게 즐기기 좋아요.
```

권장 여백은 섹션 위아래 70~120px, 제목과 설명 사이 25~40px, 본문과 이미지 사이 35~60px, 이미지와 다음 섹션 사이 60~100px이다. 여백도 디자인의 일부로 본다.

## 7. 문장·색상·장식

상품 설명은 보고서처럼 작성하지 않는다. 짧고 자연스러운 문장과 자연스러운 줄바꿈을 사용한다.

기본 배경은 흰색, 매우 연한 아이보리·베이지·회색 중 하나를 사용한다. 기본 텍스트는 검정 또는 진한 차콜이다. 상품 패키지에서 포인트 색상 하나만 가져올 수 있으나 여러 강한 색을 함께 쓰지 않는다.

짧은 밑줄, 손으로 그린 듯한 얇은 선, 작은 괄호·원·화살표, 한두 단어 포인트만 사용한다. 화려한 그라데이션, 많은 아이콘, 여러 강한 색, 반짝임, 복잡한 테두리, 큰 광고 배너, 많은 박스형 영역은 사용하지 않는다. 상품보다 디자인이 더 눈에 띄면 안 된다.

## 8. Listing별 표현과 구성

동일 상품의 여러 Listing이라도 실제 상품 정보는 유지한다. Listing별로 첫 제목, 핵심 키워드, 첫 강조문, 대표이미지, 구성 강조 순서만 다르게 표현할 수 있다.

1+1 또는 다수 구성은 첫 화면에서 `907g × 2개`, `1+1 / 총 2개 구성`처럼 수량을 명확하게 표시한다. 단품으로 오해하게 해서는 안 되며 대표이미지도 실제 판매 구성과 일치해야 한다.

## 9. 최종 디자인 검증

생성 후 다음을 확인한다.

- 전체, 핵심 텍스트, 이미지가 가운데 정렬되었는가
- 메인 상품명이 충분히 크고 모바일에서 바로 읽히는가
- 본문이 작지 않고 문장이 길지 않으며 줄바꿈이 자연스러운가
- 충분한 여백이 있고 첫 화면에 정보표나 불필요한 작은 영문 제목이 없는가
- 제품 사진이 충분히 크며 특징을 빠르게 파악할 수 있는가
- 손편지 느낌 문구와 장식이 과하지 않은가
- 상품보다 디자인이 튀지 않는가
- 묶음 수량과 Listing별 강조 키워드가 실제 정보와 일치하는가

## 10. 콘텐츠 구성 보정

### 정보 나열 대신 핵심만 선별

확인된 모든 정보를 각각 큰 SECTION으로 만들지 않는다. SECTION을 만들기 전에는 다음을 확인한다.

1. 구매 선택에 실제로 도움이 되는가
2. 앞에서 이미 전달한 내용을 반복하지 않는가
3. 이 정보 하나가 큰 화면을 쓸 가치가 있는가
4. 관련 이미지와 자연스럽게 연결되는가

하나라도 만족하지 않으면 독립 SECTION으로 만들지 않는다. 원산지, 식품유형, 제조사, 수입자, 원재료, 보관방법, 내용량, 기타 라벨 정보는 상세 후반의 **상품 정보** 영역에 한 번에 묶는다. 정보가 많다는 이유로 SECTION 수를 늘리지 않는다.

### SECTION 제목

`한 번에 확인하는 구성`, `제품 정보를 확인해 보세요`, `상품 정보를 확인해 보세요`, `라벨에 적힌 정보`, `자세히 알아볼까요`, `제품 특징을 살펴보세요`, `이런 점이 좋아요`, `구성 확인`, `기본 정보`, `제품 안내`처럼 추상적인 AI식 제목은 금지한다.

제목은 실제 특징을 직접 말한다. 예를 들어 `한 번에 확인하는 구성` 대신 `907g, 넉넉하게 두 통`, `제품 정보를 확인해 보세요` 대신 `무지방 플레인 타입`, `상품 특징을 살펴보세요` 대신 `플레인이라 더 자유롭게`처럼 쓴다. 단, 구매 설득력이 낮은 단순 고시 정보에는 억지로 제목을 붙이지 않는다.

### Hero 반복 금지와 중간 SECTION 수

Hero에서 이미 보인 용량·수량·구성을 바로 다음 SECTION에서 같은 뜻으로 반복하지 않는다. 다시 언급할 때는 한 통씩 나누어 보관하는 편의처럼 새로운 이해 포인트가 있을 때만 허용한다.

중간 핵심 SECTION은 기본 2~4개를 권장하며, 실제 강조점이 적으면 더 적게 쓴다. 우선순위는 핵심 특징, 용량·구성의 장점, 활용 방식, 구매자가 궁금해할 실제 차이점이다. 식품은 무엇인지 → 맛·타입 → 용량·구성 → 활용 방식 순으로 판단하고, 보관방법과 라벨 기반 필수 정보는 대부분 후반 상품 정보 영역에 둔다.

### 문장·이미지·여백

`~로 표기되어 있어요`, `~로 안내되어 있습니다`, `~로 확인됩니다`, `라벨에 따르면`, `구성은 ~입니다` 같은 기계적인 라벨 읽기 문장은 꼭 필요할 때만 쓴다. 소비자가 자연스럽게 읽는 문장으로 바꾼다.

각 이미지 위 문장은 해당 이미지와 직접 연결되어야 한다. 라벨 이미지는 원산지 하나만 크게 설명하지 않고 상품 정보 전체와 함께 정리하는 방향을 우선한다.

Hero는 상하 80~120px, 중요한 핵심 SECTION은 50~80px, 짧은 보조 SECTION은 35~60px, 상품 정보 영역은 40~60px 여백을 쓴다. 모든 SECTION에 같은 큰 여백을 반복하지 않는다.

### 최종 판단

같은 정보가 반복되지 않는지, 단순 고시 정보가 큰 SECTION으로 분리되지 않았는지, 추상적인 제목이 없는지, 핵심 특징만 중간에 남았는지, 상품 정보가 후반에 통합됐는지, SECTION과 이미지가 연결되는지, 페이지 리듬이 늘어지지 않는지 확인한다.
