# Image Processing Rules

## 사용 이미지

등록 이미지 출처는 사용자 제공 이미지, 코스트코 공식몰 이미지, 구매대행 상품 등록에 사용할 수 있는 공급처 이미지다. 사용자 제공 이미지가 있으면 우선 사용한다.

## 기본 이미지 가공

원본을 그대로 업로드하지 않는다. 모든 최종 출력은 EXIF·기타 메타데이터 제거, 재인코딩, 파일명 변경, 해상도·캔버스 조정, 필요 시 리사이즈와 압축률 조정을 거쳐 새 파일로 저장한다. 실제 변환과 원본·출력 해시는 `processing-manifest.json`에 기록한다.

## 대표이미지

모바일 검색 결과에서 제품이 명확히 보이게 한다. 제품 영역은 전체 이미지의 약 75~90%를 차지하게 하고 배경은 제품보다 눈에 띄지 않게 한다. 배경, 여백, 프레임, 캔버스 비율, 제품 배치 위치, 출력 해상도, 압축률을 조정할 수 있다.

## 변경 금지

제품 포장 디자인, 브랜드 로고, 제품명, 용량, 수량, 원산지, 인증표시, 원재료표, 라벨 문구를 변경하지 않는다. 색상 보정도 실제 상품과 다르게 보이지 않는 범위만 허용한다. 실제 판매 구성과 다른 수량이나 구성을 이미지에 표현하지 않는다.

## 다중 Listing 이미지

동일 상품의 여러 Listing에는 `listing-a/main.jpg`처럼 각기 다른 최종 대표이미지를 생성한다. 캔버스 비율, 제품 위치·크기, 여백, 배경, 프레임, 출력 해상도, JPEG 압축을 달리할 수 있지만 상품 자체의 실제 정보는 유지한다.

## 상세 이미지

상세 이미지도 같은 메타데이터 제거와 재저장 과정을 거친다. 긴 상세 이미지는 일정 높이로 자동 절단하지 않으며, 제목·표·설명·콘텐츠 블록이 끝나는 여백 지점을 기준으로 분할한다.
