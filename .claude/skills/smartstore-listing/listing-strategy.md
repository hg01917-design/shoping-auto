# Listing Strategy Rules

동일 상품도 검색 키워드, 가격, 배송비, 구성 전략을 달리해 여러 Listing으로 등록할 수 있다. 목적은 서로 다른 검색 키워드 조합으로 노출되는 것이다.

## 상품명 전략

브랜드, 핵심 상품명, 카테고리 키워드, 맛·종류, 용량, 수량·구성, 코스트코 키워드를 실제 정보 안에서 조합한다. Listing별로 키워드 순서와 핵심 표현을 다르게 구성한다.

## Listing 유형

- A형: 상품가 높음 / 배송비 낮음
- B형: 상품가 낮음 / 배송비 높음
- C형: 상품가와 배송비 균형
- D형: 실제 판매 구성과 일치하는 1+1, 2개 묶음, 세트, 다수 구성

가격은 [pricing.md](pricing.md)를 Listing별로 적용한다. 각 Listing은 핵심 키워드, 키워드 순서, 상품가, 배송비, 구성, 대표이미지 중 최소 하나 이상에서 실제 차이가 있어야 한다. 대표이미지는 [image-processing.md](image-processing.md)에 따라 Listing별로 별도 생성한다.
